# 上海零基础形意拳体验课预约站 · 视觉重设计

## Spec（三个方向的共同输入）

**项目是什么**
一个单页转化站：上海静安，90 分钟形意拳入门体验课，零基础可参加，中英双语，国内外客人都能下单（Stripe / PayPal / 微信）。域名 hishifu.oneding.tech。技术栈 Next.js App Router + Tailwind v4，现有 token 在 `src/app/globals.css`，骨架是 `max-w-3xl` 单列（深色 hero + 一叠白卡片 + 场次列表）。

**受众与场景**
两拨人：国内用户（微信支付、关心地址与地铁）、海外用户（卡支付、关心「我零基础身体一般能不能去」）。共同的心理门槛是**陌生感**，不是价格。绝大多数流量在手机上，落地到点「选择场次」三屏内完成。

**核心信息（按优先级）**
1. 90 分钟、零基础、穿运动服就能来
2. 这 90 分钟里具体做什么（热身 10 / 三体式站桩 20 / 五行拳 35 / 呼吸发力 15 / 放松答疑 10）
3. 在哪、怎么走（静安，地铁 2/12/13 号线南京西路站步行 5 分钟）
4. 哪天有、多少钱（¥168 起）、还剩几个位
5. 只要邮箱就能订，不用注册

**情感基调**
有反差、有力量、但不凶。（用户原话）

**输出格式与尺寸（三版统一）**
单文件 HTML。桌面 1440×900，移动 375×812。每版交付完整一页：首屏 → 课程说明 → 场地 → 场次列表 → 下单入口。

**已知约束**
正文 ≥14px（移动端 16px）、标签 ≥12px、可点元素 ≥44×44px、对比度 ≥4.5:1。中英双语（demo 出中文版）。不编造真实照片与评价。

**素材**
程序化 SVG 共用两套：①三体式站桩结构线稿（含重心垂线与角度标注）②五行拳五格序列（劈崩钻炮横）。照片位诚实留空，交付时换成真图。

**外观账本避让**
最近 5 个交付全是深色大屏 + 微软雅黑无衬线。三个方向**都不做深色大屏**，至少两个方向不用默认无衬线标题。

## 六个候选

### A · 最佳设计师｜吕敬人（Lü Jingren）
- **逻辑与来源**：吕敬人，中国书籍设计「书衣大师」，《中国记忆》2009 世界最美的书荣誉奖。他把设计看成与文本互动的系统工程，不只是封面。
- **借的是什么**：版心呼吸——版心上提、天头小、地脚很大、不居中；切口一侧留一条窄旁注栏；暖纸底 #F4EFE4 + 墨黑；**朱砂红全站只用一处**；行距 2 以上；书眉与页码极小。
- **主角素材**：三体式站桩结构线稿（SVG），旁注栏写「重心 / 呼吸 / 膝不过脚尖」的小注。
- **骨架**：单栏版心，上提靠左；切口一侧窄旁注栏；内容按「一 / 二 / 三」章节推进，不用 01/02。
- **胆量花在哪**：整站只有一处朱砂红——那颗「报名」印章，其余全部墨黑纸色。
- **form 来自内容的哪里**：形意拳讲「心意诚于中，肢体形于外」，页面就该是一本书的呼吸节奏，慢，不催。

### B · 最佳设计师｜Experimental Jetset（荷兰）
- **逻辑与来源**：Experimental Jetset，阿姆斯特丹三人组，Helvetica + 严格网格 + 概念性排版，不做装饰。
- **借的是什么**：单一无衬线字族；一切对齐到基线网格；纯黑纯白 + 一抹概念色（这次取钢蓝 #1F3A93，避开账本里的朱红）；字号极端反差，正文反而小；零圆角零阴影零渐变。
- **主角素材**：纯文字——「90」这个数字被放大到占满首屏宽度，下面是 14px 的一行说明。
- **骨架**：12 栏网格，标题顶到上边界占 8 栏；课程流程做成表格式对齐；五行拳「劈 崩 钻 炮 横」横排压在网格线上。
- **胆量花在哪**：首屏没有一个像素的装饰、没有图、没有色块，只有一个数字。
- **form 来自内容的哪里**：形意拳「动作极少、招式简练」——页面也只留下必要的东西。

### C · 现实参照｜Aesop（Work & Co）
- **逻辑与来源**：Aesop 官网由 Work & Co 重做，International Website Winner 2018、Innovation by Design Award、2019 最佳购物网站 Honoree，上线 60 天转化 +15%。**同媒介（品牌官网 / 预约型服务）**。
- **借的是什么**：象牙纸底 #FFFEF2 + 暖炭黑 #333333（不用纯黑）；**0px 圆角**；零阴影；h1 只有 36px / weight 400，层级全靠留白；section 之间用 96px+ 的间距而不是分割线；图片硬边裁切；深度只靠色温（暖砂面板 #F7ECDD 比底色深半档）。
- **主角素材**：场地照片位 + 「成分式」长文案——把 90 分钟拆成五段，每段两行。
- **骨架**：居中窄栏 + 奢侈留白，区块之间靠呼吸分隔，没有卡片没有边框。
- **胆量花在哪**：全场最大字号只有 36px，反差全靠留白，不靠字号。
- **form 来自内容的哪里**：体验课和护肤咨询一样是**高接触服务**，文案承担转化，界面退场。

### D · 现实参照｜On（on-running.com）
- **逻辑与来源**：On，瑞士运动品牌。单色 + 单一电光蓝 #007AFF；巨号标题压在真实运动摄影上；等宽字只用于交互元素（按钮、时间、价格）；摄影必须显示真实运动而非摆拍。**同媒介，且同为身体/运动题材**。
- **借的是什么**：极端字号反差（巨标题 vs 12px 标签）；全幅 hero 照片压白字；等宽字只用在按钮 / 时间 / 价格三处；hero 巨幅留白；正文区回到结构化栅格。
- **主角素材**：动作照片位（压字）+ 下方结构化栅格的课程流程。
- **骨架**：全幅 hero 图（白字压图）→ 结构化栅格信息区 → 场次列表。
- **胆量花在哪**：标题压在照片上，只用一处蓝，其余纯黑白。
- **form 来自内容的哪里**：「教练会逐一纠正动作」——真实、动态、在发生，不是摆拍。

### E · 秒数轮盘｜web #17 功能主义网格社区 Functional Brutalism
- **逻辑与来源**：秒数轮盘，web 分区 20 种，S=35 → 原抽 #16 终端核软未来，但该风格是「深·近黑底 + 等宽无衬线」，与外观账本最近交付（深·近黑底 #0C0D0F 无衬线）同类，**顺延一号到 #17**。原型：Are.na / Lobsters / Quartz，Müller-Brockmann 栅格 + Tufte 信息密度。还原 98%。
- **借的是什么**：近白底 #FBFBFB + 黑字 + 1px 灰发丝线 #E0E0E0 + 经典链接蓝 #0000EE；系统字栈；高密度信息列表；极小留白；紧凑行距；信息密度优先于视觉。
- **主角素材**：场次列表本身——就是一张密排时刻表。
- **骨架**：一栏到底的信息流，发丝线分隔，「日期 / 时段 / 余位 / 价格」四段严格对齐。
- **胆量花在哪**：不做 hero，第一屏就是可报名的场次列表。
- **form 来自内容的哪里**：预约站的本质就是一张时刻表，那就老老实实做一张时刻表。

### F · 秒数轮盘｜east #12 日式生活杂志密排（POPEYE / BRUTUS）
- **逻辑与来源**：秒数轮盘，中文与东亚分区 12 种，S=35 → #12。原型 POPEYE（1976 创刊，Magazine House，「Magazine for City Boys」）与 BRUTUS。还原 78%。
- **借的是什么**：白纸黑字；黄色马克笔下划线压大标题；**手写体红蓝笔注解**；3×3 数据格（黄格与黑格各用一两格强调）；图解上编号圆点 + 引线；窄体拉丁做书眉页码。
- **主角素材**：90 分钟课程的「图解时间表」——五个环节画成一条路线图，带编号圆点。
- **骨架**：上：大标题 + 马克笔线；中：流程路线图；下：3×3 数据格（时长 / 人数 / 价格 / 语言 / 地址 / 地铁 / 退改 / 装备 / 年龄）。
- **胆量花在哪**：把一节课做成一张「城市攻略图」。
- **form 来自内容的哪里**：这不是一门课，是**一次城市生活体验**——上海、周末、90 分钟、出门就能去。
